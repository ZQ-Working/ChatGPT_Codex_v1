# 下载与使用

## 最新版本：气温之境（沉浸式3D）

请下载“中国气温沉浸式3D课件_新版.zip”，解压后用最新版Edge/Chrome打开“中国气温沉浸式3D课件.html”。也可直接下载本目录的同名HTML单文件。

三维地形占满画面，支持鼠标旋转、缩放、地标聚焦、冬夏转场、电影式巡游、温度带图层和作物生长实验。无需联网或安装；浏览器需支持WebGL。具体操作和模型边界见“3D新版使用说明.md”，测试范围见“3D新版验收记录.md”。

在GitHub点击文件，再点“Download raw file / 下载原始文件”。也可以在分支页面点“Code → Download ZIP”下载整个仓库。

## 历史版本

“中国气温互动课件.html”和“中国气温互动课件_离线完整版.zip”是先前的任务卡式版本。新版请使用文件名中含“沉浸式3D”的文件。
