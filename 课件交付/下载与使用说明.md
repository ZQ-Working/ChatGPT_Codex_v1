# 下载与使用

本目录包含可独立运行的HTML课件和离线完整版ZIP。

在GitHub打开本分支的“课件交付”目录，点击“中国气温互动课件_离线完整版.zip”，再点“Download raw file / 下载原始文件”。下载后解压，用最新版Edge或Chrome打开“中国气温互动课件.html”。

也可以在分支页面点“Code → Download ZIP”下载整个仓库，再进入本目录。

无需安装或联网。完整包内含教师说明、学生任务单、设计计划和验收记录。课堂使用前请在实际教学电脑上试运行。

课件使用明确标注的区域关系示意，不是精确地理地图。浏览器测试范围与限制见ZIP中的验收记录。
